# Privacy Policy

*Last updated: 2026-07-24*

## Summary

forensic-vfs-mount is a local Rust library. It does not collect, transmit, or store any personal data on remote servers.

## Data Access

forensic-vfs-mount is an in-memory adapter over a `forensic-vfs` filesystem. It reads only the bytes the underlying filesystem hands it and performs all processing on your local machine. Nothing is uploaded anywhere.

## Telemetry

forensic-vfs-mount has **no telemetry**. It makes no network requests of any kind.

## Open Source

forensic-vfs-mount is open source (Apache-2.0). You can audit every line of code at [github.com/SecurityRonin/forensic-vfs-mount](https://github.com/SecurityRonin/forensic-vfs-mount).
